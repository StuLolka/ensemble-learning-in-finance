# Применение ансамблевых методов для анализа доходности биржевых акций

Данный репозиторий содержит код и материалы исследовательского проекта, посвящённого применению ансамблевых методов машинного обучения для прогнозирования доходности и направления изменения цен акций на основе исторических данных.

Проект реализован в формате Jupyter Notebook и сопровождается пояснительной запиской, включающей анализ данных, описание моделей и интерпретацию результатов.

---

## Датасет

В проекте используется набор данных [MOEX Shares Prices (since 2004)](https://www.kaggle.com/datasets/alexanderkobzar/moex-shares-prices-since-2004), опубликованный на Kaggle пользователем Alexander Kobzar.

Исходный набор данных содержит 2 437 686 записей по 2 768 ценным бумагам Московской биржи (MOEX).

После предварительной обработки данных и формирования признаков осталось 1 022 418 наблюдений по 618 ценным бумагам.

---

## 📌 Цели проекта

- Исследовать применимость ансамблевых моделей к задаче прогнозирования доходности акций.
- Сравнить качество различных алгоритмов:
  - RandomForest  
  - ExtraTrees  
  - XGBoost  
  - LightGBM  
  - HistGradientBoosting  
  - Ridge Regression  
  - KNN
- Оценить качество ансамблей: VotingRegressor, взвешенное голосование, blending.
- Проверить точность прогноза **величины доходности** и **направления изменения цены**.
- Проанализировать устойчивость моделей на выборке из сотен временных рядов.
- Оценить влияние подбора гиперпараметров и веса моделей на итоговый ансамбль.
- Измерить временные характеристики всех алгоритмов.

---

## 📊 Метрики

В проекте используются две ключевые метрики:

- **SMAPE (Symmetric Mean Absolute Percentage Error)** — симметричная средняя абсолютная процентная ошибка;
- **Direction Accuracy** — доля правильно предсказанного направления изменения цены.

Эти метрики позволяют оценить как точность прогноза по значению, так и практическую полезность модели.

## 🧠 Используемые модели

- RandomForestRegressor  
- ExtraTreesRegressor  
- XGBoostRegressor  
- LightGBMRegressor  
- HistGradientBoostingRegressor  
- Ridge Regression (в составе Pipeline)
- KNeighborsRegressor (в составе Pipeline)

Для каждой модели реализованы также версии с подобранными гиперпараметрами.

---

## 🧩 Ансамблирование

В проекте изучены следующие стратегии:

### 1. VotingRegressor (без весов)
Используются все модели с равным вкладом в итоговое предсказание.

### 2. VotingRegressor (с весами)
Сильнейшие модели получают увеличенный вес, слабые — минимальный.

### 3. Ансамбль сильнейших моделей
Комбинация RandomForest, ExtraTrees и XGBoost (без весов и с весами).

### 4. Blending
Предсказания базовых моделей объединяются с помощью мета-модели Ridge.
